# Alberta 

Note: The AESO data from 2017 to 2020 and 2020 to 2023 do not match on May 1 2020. The difference between the two is added 
to the 2020-2023 data in order to eliminate the discrepancy. This seems to be supported by the plot on Page 8 of the 
[2020 Annual Market Statistics](https://www.aeso.ca/download/listedfiles/2020-Annual-Market-Stats-FINAL.pdf), 
which are very similar to the monthly average load obtained after this correction.
